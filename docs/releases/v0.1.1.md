# OmniChat v0.1.1 — Android 測試版

## 更新內容

- 修正逐字稿面板底部收音按鈕超出畫面的問題，改用討論頁的可用高度。
- 新增底部分頁左右滑動與淡入淡出動畫，功能表保持原位。
- 新增討論畫面向下收起、向上展開動畫。
- 調整右側逐字稿展開／收合動畫，遮罩同步淡入淡出，保留閱讀位置。
- 改善轉場期間的操作保護，避免離場頁面重複觸發按鈕與彈窗。

使用者已確認本次功能驗證完成。GitHub Actions 會提供 `OmniChat-v0.1.1-debug.apk` 與 `SHA256SUMS.txt`；雲端產出的 APK 可下載後自行測試。

完整更新紀錄見 [CHANGELOG.md](https://github.com/ThorSheep/OmniChat-Android/blob/main/CHANGELOG.md)。
