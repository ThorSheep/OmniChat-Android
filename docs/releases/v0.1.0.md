# OmniChat v0.1.0 — Android 測試版

首個 Android 公開測試版本，供手動安裝與驗收。

## 功能

- HTTPS 伺服器設定及可選的預設測試 API 網址。
- 註冊、登入、恢復登入、登出、改名、改密碼及學生／老師／管理員身分顯示。
- 保存多個討論室入口，以六碼代碼加入，一次只加入一個房間。
- 即時語音轉文字、最終文字提交、多人與 AI 文字訊息、成員狀態及斷線同步。
- 獨立討論畫面、收起狀態列、右側逐字稿與本人醒目標示。
- 遠端討論紀錄、本機逐字稿及淺色／深色／跟隨系統。

## 下載與安裝

GitHub Actions 會由此標籤的原始碼建置 `OmniChat-v0.1.0-debug.apk`，並附上 `SHA256SUMS.txt`。最低 Android 8.0（API 26）。

這是 Debug APK，尚未設定固定的正式發布簽章。CI 簽章可能與既有安裝不同，不能保證直接覆蓋更新；如需移除舊版，請先保留所需本機資料。

## 驗證與已知限制

- 使用者已回報本機版本驗證完成；CI 產出的 APK 由使用者另外手動測試，不將本機驗證視為 CI APK 已通過驗收。
- 這個發布工作流程僅建置 APK，不代表 lint、單元測試或實機情境已全部通過。
- 使用系統語音辨識，靜音後重啟辨識可能有提示音；部分裝置辨識需網路。
- Cloudflare Quick Tunnel 測試網址可能變動，可在 App 編輯伺服器設定。
- 不上傳原始音訊、不播放 AI 語音；背景、藍牙及長時間情境依裝置實測。
